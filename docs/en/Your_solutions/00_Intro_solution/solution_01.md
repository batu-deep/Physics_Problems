# Solution 01 — Vector Algebra

## Given

a = [2, 1, -3]  
b = [4, -2, 1]

---

## a) Magnitudes

Magnitude formula:

|v| = sqrt(x² + y² + z²)

For vector a:

|a| = sqrt(2² + 1² + (-3)²)  
|a| = sqrt(4 + 1 + 9)  
|a| = sqrt(14) ≈ 3.7417

For vector b:

|b| = sqrt(4² + (-2)² + 1²)  
|b| = sqrt(16 + 4 + 1)  
|b| = sqrt(21) ≈ 4.5826

---

## b) Dot Product

Dot product formula:

a · b = a₁b₁ + a₂b₂ + a₃b₃

a · b = (2×4) + (1×-2) + (-3×1)  
a · b = 8 − 2 − 3  
a · b = 3

---

## c) Cross Product

Cross product formula:

a × b = [a₂b₃ − a₃b₂ , a₃b₁ − a₁b₃ , a₁b₂ − a₂b₁]

Substitute values:

a × b = [ (1×1 − (-3×-2)), ((-3×4) − (2×1)), (2×-2 − 1×4) ]

a × b = [1 − 6 , -12 − 2 , -4 − 4]

a × b = [-5, -14, -8]

---

## d) Angle Between Vectors

Formula:

cos(θ) = (a · b) / (|a||b|)

cos(θ) = 3 / (sqrt(14) × sqrt(21))

sqrt(294) ≈ 17.146

cos(θ) ≈ 3 / 17.146  
cos(θ) ≈ 0.175

θ = arccos(0.175)

θ ≈ 79.9°
