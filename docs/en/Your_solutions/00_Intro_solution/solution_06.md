# Solution 06 — Function Analysis

Function:

f(x) = 3x² − 12x + 7

Derivative:

f'(x) = 6x − 12

Set derivative equal to zero:

6x − 12 = 0

x = 2

Evaluate function:

f(2) = 3(2²) − 12(2) + 7

f(2) = 12 − 24 + 7  
f(2) = -5

Second derivative:

f''(x) = 6 > 0

Therefore the point is a minimum.

Final answer:

Minimum point:

(2, -5)
